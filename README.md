# Cabin Rental Landing Page

Una moderna página de aterrizaje para alquiler de cabañas construida con Next.js y React.

## 🏠 Características

- Diseño responsivo y moderno
- Sección de héroe atractiva
- Galería de imágenes
- Sección de características destacadas
- Formulario de contacto
- Componentes reutilizables con shadcn/ui

## 🚀 Tecnologías Utilizadas

- **Next.js** - Framework de React para aplicaciones web
- **React** - Biblioteca de JavaScript para construir interfaces de usuario
- **Tailwind CSS** - Framework de CSS para diseño rápido
- **shadcn/ui** - Componentes de UI reutilizables
- **JavaScript/JSX** - Lenguaje de programación

## 📦 Instalación

1. Clona el repositorio:
```bash
git clone [URL_DE_TU_REPOSITORIO]
cd cabin-rental-landing-page
```

2. Instala las dependencias:
```bash
npm install
# o
pnpm install
```

3. Ejecuta el servidor de desarrollo:
```bash
npm run dev
# o
pnpm dev
```

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la aplicación.

## 📁 Estructura del Proyecto

```
cabin-rental-landing-page/
├── app/                    # App Router de Next.js
├── components/             # Componentes reutilizables
│   ├── ui/                # Componentes de UI (shadcn/ui)
│   ├── hero-section.js    # Sección principal
│   ├── gallery-section.js # Galería de imágenes
│   ├── features-section.js# Características
│   ├── contact-section.js # Formulario de contacto
│   └── footer.js          # Pie de página
├── hooks/                 # Custom hooks
├── lib/                   # Utilidades
├── public/                # Archivos estáticos
└── styles/                # Estilos globales
```

## 🛠️ Scripts Disponibles

- `npm run dev` - Inicia el servidor de desarrollo
- `npm run build` - Construye la aplicación para producción
- `npm run start` - Inicia el servidor de producción
- `npm run lint` - Ejecuta el linter
